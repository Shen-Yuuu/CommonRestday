## Global Constraints

- 编译目标 **API 26（SDK 26.0.0）**，`compileSdkVersion`/`targetSdkVersion`/`compatibleSdkVersion` 三项同为 26.0.0，Stage 模型，ArkTS 严格模式（`strictMode.useNormalizedOHMUrl: true`）。
  > 更正：旧稿这里写"API 21（6.0.1(21)）"。Task 5.2 起按 API 26 单档 + 渐进增强执行。
- `domain` HAR 禁止 import 任何 `@kit.*` 与 data 层——保证纯逻辑可单测。**已复验：`domain/src/main` 零 `@kit.` import。**
- 单人功能必须 100% 离线可用；云端不落任何班表明文（只存 AES-256-GCM 密文快照）。**云端整体受 `CLOUD_BLOCKED` 门禁**（Task 0.4）：HUKS 长期密钥链路未验证前不启用，不允许退回"短码派生长期密钥"。
- 权限最小化：`module.json5` 实际只声明 READ/WRITE_CALENDAR、PUBLISH_AGENT_REMINDER、INTERNET 四条；不申请定位/通讯录/健康/网络状态；相机与相册一律走 Picker 免权限路径。
- 每个任务合并前必须通过：本地单测（`node tools/test/run.mjs`）+ hvigor 构建无 error；提交信息用 conventional commits（`feat:`/`fix:`/`test:`/`docs:`/`chore:`）。
- UI 全部走资源引用（string/color），深色模式同步适配；不写死中文到布局。**新增发布门禁项**：360vp、横屏、2.0× 系统字体、长辈模式、减弱动效、读屏语义。
