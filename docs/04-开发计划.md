**Goal:** 交付"同休日"HarmonyOS 首版：双人班表 → 共同可用时间 → 计划/日历/卡片 的完整闭环，可上应用市场。

**Architecture:** 单 entry HAP + 分层 HAR（domain 纯逻辑层 / data / cloud / feature），本地优先，AGC 云函数+云数据库仅承载加密快照交换。详见架构文档。

**Tech Stack:** ArkTS + ArkUI（状态管理 V2）、ArkData（relationalStore/Preferences）、Cloud Foundation Kit、Core Vision Kit、Calendar Kit、Form Kit、Notification Kit、Scan Kit、Account Kit；（P1）Live View Kit、OneHop Kit、Push Kit。

**Spec:** [01-产品设计文档](./01-产品设计文档.md) · [02-技术架构设计](./02-技术架构设计.md) · [03-功能链路设计](./03-功能链路设计.md)

## Global Constraints

- 编译目标 API 21（6.0.1(21)），Stage 模型，ArkTS 严格模式（现有工程 `strictMode.useNormalizedOHMUrl: true` 保持）。
- `domain` HAR 禁止 import 任何 `@kit.*` 与 data 层——保证纯逻辑可单测。
- 单人功能必须 100% 离线可用；云端不落任何班表明文（只存 AES-256-GCM 密文快照）。
- 权限最小化：不申请定位/通讯录/健康；相机与相册一律走 Picker 免权限路径。
- 每个任务合并前必须通过：本地单测 + hvigor 构建无 error；提交信息用 conventional commits（`feat:`/`fix:`/`test:`/`docs:`）。
- UI 全部走资源引用（string/color），深色模式同步适配；不写死中文到布局。

## M0 环境与骨架（W1）

**任务：**
1. AGC 开通：创建项目与应用（包名 `com.huawei.commonrestday`）、开通云函数/云数据库/认证（华为账号登录）、生成 `agconnect-services` 配置接入工程。
2. 签名：申请调试/发布证书与 Profile，双真机（HarmonyOS 5+ / 6.x）安装调通。
3. 工程重构为分层骨架：创建 `commons/domain/data/cloud/feature` HAR 模块，配置依赖方向（entry → feature → domain/data/cloud），`domain` 设为无 Kit 依赖（CI 里可用 lint 断言 import）。
4. 测试基座：LocalUnit（hypium）跑通一条示例单测；`hvigorw assembleHap` 与 `onDeviceTest` 脚本化。
5. 合规占位：隐私政策页面壳 + 首启弹窗框架；登记 **App 备案** 流程启动（周期长，本周发起）。
6. 权益申请启动（流程长，本周发起）：实况窗权益、推送服务（P1 备用）、OneHop 合作咨询。

**DoD：** 空壳 App 显示"框架就绪"页；一条示例单测在 CI 脚本下通过；AGC 控制台四项服务可见。

## M1 班表内核（W2–W3，最高风险控制点）

**任务（TDD，先测后码）：**
1. `domain/model`：`ShiftType/ShiftInstance/Interval/Window/ScheduleSnapshot` 与日期工具（锚点、跨天、月末）。
2. `domain/expand`：循环展开（1–31 天序列 + anchor + override 覆盖）+ 课程展开（weekday/周次/单双周/节次模板）。用例：31 天循环跨月、override 回退、第 17 周无课。
3. `domain/buffer`：通勤并入、夜班判定（与 00:00–05:00 相交）、恢复块、作息裁剪（起床/就寝/收尾）。用例：22:30–06:00 与 20:00–02:00 夜班；恢复参数=0。
4. `domain/merge`：排序合并、双指针求并、取补。用例：全忙/全闲/完全交叠/相邻 1 分钟接续。
5. `domain/classify`：八个标签判定（MEAL…STUDY），参数可注入。
6. `engine`：管线门面 + PRD F4 示例固定断言（周六 15:00—22:30 / 7h30m）+ 120 天性能基准（<50ms）。
7. `data` 层：建表（架构文档 4.1 SQL）、Dao、Repository；`Preferences` 参数项。
8. 快照序列化/反序列化（三等级位图/标签/精确区间）+ 单测。

**DoD：** `domain` 行覆盖 ≥80%；示例演算断言通过；全链无 Kit import；data 层 CRUD 单测通过。

## M2 班表录入（W4–W5）

**任务：**
1. 导航骨架：Index(Tabs：首页/共同/计划/我的) + Navigation 路由表。
2. 班次类型编辑器（时间/跨天/通勤/恢复/颜色，允许活动开关）。
3. 循环模板创建 + 120 天月历预览（L2 链路）。
4. 涂抹月历组件：懒加载网格、滑动连续标记、长按单日菜单、override 半透明显示（L3）。
5. OCR 链路：CameraPicker/PhotoViewPicker → Core Vision Kit 识别 → 网格解析规则（表头/姓名列/符号映射）→ 确认页（低置信高亮+原图对照）（L4）。
6. 课程表：文本粘贴解析、手动添加、学期锚点与节次模板设置、周视图预览（L5）。
7. 20 张 OCR 样本集建立与首轮成功率度量（目标 ≥85%）。

**DoD：** L2–L5 手工走查通过；无网状态下四种录入全部可用；OCR 样本报告落盘 `docs/ocr-report.md`。

## M2.5 双人闭环（W5–W6，v1.1 新增，当前里程碑）

**任务：**
1. domain：STUDY 标签（工作日 08:00–21:00 内 ≥2h）+ 伴侣忙区间构建辅助函数 + 计划冲突检测纯函数（排除自身占用的交叠判定 + 替代窗口推荐）+ 对应单测。
2. data：班表四表增加 `owner` 列（ME/PARTNER）+ Repo 方法 owner 化；SettingsStore 增加伴侣参数、隐私弹窗已读标记、伴侣昵称。
3. feature：ScheduleUseCase 接线——引擎参数真实读写 SettingsStore、伴侣班表装配进 recompute、重算后冲突检测回写 plan 状态；暴露保存后触发重算的统一入口。
4. entry：① 首启隐私弹窗；② 我的页：引擎参数编辑 + 隐私等级切换 + 添加/管理伴侣；③ 伴侣课表导入页（复用课程导入，owner=PARTNER）+ 伴侣班表涂抹（复用涂抹页）；④ 共同窗口页（标签筛选：≥2h/半天/同休日/周末/共同自习/旅行）；⑤ 窗口详情 + 创建计划（窗口内硬限制）+ 计划列表/取消；⑥ 录入保存后事件驱动重算；⑦ 首页三卡切"我们"语义。
5. 修复既有断链：term_config.section_times 读取接线；nightMode/allowActivity 暴露到班次编辑 UI。

**DoD：** 双份不同专业课表（含单双周差异）→ 共同窗口正确（含 STUDY 标签）→ 创建计划占用时段 → 改课表触发自动重算且冲突计划标红并给替代窗口；修改就寝/恢复参数后首页结果随之变化；全部既有单测 + 新增单测通过；构建零 error。

## 里程碑后的实施计划（per writing-plans）

每个里程碑开工时生成 bite-sized TDD 实施计划（保存 `docs/plans/YYYY-MM-DD-mX-<name>-plan.md`）：任务内分"写失败测试 → 跑红 → 最小实现 → 跑绿 → 提交"五步，含精确文件路径与接口签名。可由 AI 以子代理逐任务执行、主会话按任务验收。
