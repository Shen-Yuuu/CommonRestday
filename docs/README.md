## 一页纸摘要

**做什么**：一款 HarmonyOS 原生 App。两个人各自录入班表（循环模板 / 日历涂抹 / 拍照 OCR / 大学生课程表），App 在本地计算并筛选"扣除睡眠、通勤、恢复时间后**真正可用**的共同空闲窗口"（今晚有空几小时 / 下个完整同休日 / 适合短途旅行的连续空档），一键变成写入双方系统日历的共同计划；班次变化时自动重算并提示冲突与替代时间；桌面服务卡片常驻显示"距离下次共同休息还有 N 天"。

**目标用户**：护士/医生与家属、工厂倒班、民航铁路公交、警务消防安保、零售餐饮酒店、一方倒班一方正常班的情侣/夫妻、接送孩子的双职工家庭、**大学生情侣（课程表场景）**。

**技术底座**（HarmonyOS NEXT，API 21 / 6.0.1，仅手机首版）：

| 能力 | 用到的 Kit | 备注 |
|------|-----------|------|
| 班表 OCR 识别 | Core Vision Kit（端侧离线） | 无需联网，隐私友好 |
| 写入系统日历 | Calendar Kit | 需 READ/WRITE_CALENDAR 动态授权 |
| 桌面服务卡片 | Form Kit（ArkTS 卡片） | 2x2 / 2x4 两规格 |
| 当天计划倒计时 | Live View Kit 实况窗 | **上架前需申请实况窗权益** |
| 碰一碰配对 | OneHop Kit（NFC+软总线） | 三方接入需合作申请，P1，降级方案为二维码/邀请码 |
| 云端配对与快照交换 | Cloud Foundation Kit（AGC 云函数+云数据库） | 云端只存加密快照，不可读内容 |
| 本地存储与计算 | ArkData（RDB/Preferences）、纯本地算法 | 计算毫秒级，无后台常驻 |
| 通知提醒 | Notification Kit（+P1 Push Kit） | 换班冲突、每周共同时间摘要 |

**首版边界**：两人配对 ✅；三人群组 / 企业考勤 / 薪资 / 自动健康建议 / 天气酒店推荐 / AI 陪伴 / 社区 ❌（二期以后）。单人使用永久免费，双人共同时间功能买断。

## 已确认的关键决策

1. **同步后端**：华为 AGC 云开发服务（Cloud Foundation Kit 云函数 + 云数据库），配对身份基于华为账号（Account Kit），异地配对可覆盖；当面配对（二维码/碰一碰）密钥端到端协商。
2. **资源假设**：1 名开发者 + AI 辅助，按全职 10–12 周排期。
3. **设备范围**：首版仅手机（`deviceTypes: phone`），手表/平板分布式列入二期。
4. **新增场景**：大学生课程表作为一等班次来源接入（课程 = 固定忙碌块，支持周次范围/单双周/节次模板），并衍生"共同自习/无课空档"筛选场景。
