## 二、产品背景与设计动机

「两人份」帮助两个人找到共同空闲时间。「共同休时」页是核心功能页，页头需要在不增加操作负担的前提下传递情感温度。

角色动画的三层作用：

1. **情感表达**——让「两个人的时间」有可感知的存在感，而不是纯数据列表
2. **记忆点**——建立属于应用的原创角色 IP，为后续场景延伸打基础
3. **解压互动**——点击触发的捏压反馈，在用户等待数据或短暂停留时提供微小的愉悦

一句话设计理念（不写入插画，转化为角色关系与动作）：

> 各自忙碌，也在为彼此留一点时间。

## 三、角色造型标准

### 3.1 选定方向：B「探头气泡」

核心构图：**休休在前（左侧），布布在后（右侧），前后层次而非并排**。休休的身体遮住布布约 40%，布布只露出右半脸、右耳、右爪。

这个构图解决了 112 × 56 逻辑单位内两张脸并排会过于拥挤的问题，同时天然形成"一个主动探头、一个慵懒陪伴"的叙事关系。

### 3.2 休休（兔）标准形

| 属性 | 规格 |
|---|---|
| 主色 | 纯白 `#FFFFFF` |
| 描边色 | 玫粉 `#E890A8`，宽度 2.5～3px（深色模式下取 3px） |
| 耳朵内色 | 粉色渐变 `#FFD2E0` → `#FFBDD0`，由耳根向耳尖 |
| 腮红 | 淡粉椭圆 `#FFC7D8`，透明度 70%，不超过眼宽 |
| 眼睛 | 深色圆点 `#5C4750`，左眼直径略大于右眼（比例约 1.15:1） |
| 耳朵方向 | 左耳向外自然垂落，右耳向内微倾（靠向布布），不对称是辨识特征 |
| 身体可见范围 | 全身在画框内，底部约 20% 被画框边缘截断 |

### 3.3 布布（熊）标准形

| 属性 | 规格 |
|---|---|
| 主色 | 暖杏奶油色 `#FFE3C2` |
| 描边色 | 暖橙 `#D9A06B`，宽度 2.5～3px |
| 腮红 | 浅橙椭圆 `#FFC7A8`，透明度 65% |
| 眼睛 | 弧线眼（非圆点），一眼半眯（慵懒），一眼微睁，两眼不对称 |
| 可见范围 | 右半脸 + 右圆耳 + 右下方爪子，左侧被休休遮住 |
| 爪子 | 颜色比主体浅一档（`#FFEEDD`），圆润，悬于右下角 |

### 3.4 构图比例（112 × 56 容器内）

```
┌─────────────────────────────────────┐  ← 112px 宽
│                                     │
│  [休休全身·左55%]  [布布右半·右45%] │  ← 56px 高
│                          [布布右爪] │
└─────────────────────────────────────┘
```

- 休休头部中心约在容器左侧 38% 处
- 布布头部中心约在容器右侧 25% 处
- 布布爪子中心约在容器右侧 10%、底部 80% 处
- 两角色在水平方向有约 15% 的重叠（休休覆盖布布）

### 3.5 深色模式适配

- 休休白色主体在深色背景上依靠 3px 玫粉描边保持轮廓，不加任何白色底板
- 布布暖杏色在深色背景下略调高饱和度（深色令牌由 DesignTokens 管理，SVG 描边宽度统一改 3px）
- 两者均不使用投影、发光或底板——纯透明背景

## 四、表情变体系统

每个角色需要 4 套可切换的脸部表情帧，通过图层透明度切换实现。

### 4.1 休休表情变体

| 编号 | 状态名 | 眼睛形态 | 嘴部形态 | 用途 |
|---|---|---|---|---|
| `xiuxiu-face-0` | 默认·平静 | 双圆点，左略大 | 嘴角微扬，平静 | 静止待机 |
| `xiuxiu-face-1` | 发现·好奇 | 两眼稍大，微张 | 嘴微开（"哦？"） | 叙事动画转折点 |
| `xiuxiu-face-2` | 开心·回应 | 一眼眯弧，一眼圆 | 嘴角上扬，露小牙 | 叙事动画互动高潮 |
| `xiuxiu-face-3` | 困了·安静 | 两眼半闭下垂 | 嘴角回平 | 「困了靠过来」动画 |

### 4.2 布布表情变体

| 编号 | 状态名 | 眼睛形态 | 嘴部形态 | 用途 |
|---|---|---|---|---|
| `bubu-face-0` | 默认·慵懒 | 一眼半眯，一眼微睁 | 嘴角微扬，满足感 | 静止待机 |
| `bubu-face-1` | 察觉·注意 | 半眯眼稍睁，右耳前倾 | 嘴型不变 | 叙事动画察觉时刻 |
| `bubu-face-2` | 被逗·开心 | 双眼弯弧 | 嘴角上扬 | 叙事动画互动高潮 |
| `bubu-face-3` | 将睡·闭眼 | 双眼闭合 | 嘴微开（哈欠前兆） | 「困了靠过来」动画 |

## 五、页头布局规范

### 5.1 组件位置

`CoTimeView.ets` 的 `header()` 方法目前为纯文字 Column。
实现时需改为 Row，左侧放文字列，右侧放角色容器：

```
Row({ space: 10 }) {
  Column({ space: 2 }) {       // 左·文字列（layoutWeight: 1）
    Text('共同休时')
    Text(subtitle)
  }
  CompanionsDuo()              // 右·角色组件（固定宽度）
}
```

### 5.2 角色容器尺寸

| 参数 | 数值 | 说明 |
|---|---|---|
| 标准宽 | 112 vp | 参考基准，可根据实际排版微调 ±8vp |
| 标准高 | 56 vp | 与标题行自然对齐，不增加页头高度 |
| 最小宽（360屏） | 100 vp | 窄屏下缩减，角色比例不变 |
| 背景 | 完全透明 | 无底板、无边框、无投影 |
| 点击区域 | 整个容器 112 × 56 | 不要求精确点到角色，全区域响应 |

## 六、待机循环动画

用户打开页面后默认播放，无限循环，纯装饰，不传递业务状态。

### 6.1 呼吸陪伴（基础循环）

| 参数 | 值 |
|---|---|
| 缩放幅度 | ±1.5%（scale 在 0.985 ～ 1.015 之间） |
| 呼吸周期 | 2.8 秒 |
| 缓动 | `Curve.EaseInOut` |
| 两角色相位差 | 布布延迟 0.4 秒开始，模拟各自呼吸不同步 |

**偶发微动（随机叠加在呼吸循环之上）：**

| 触发频率 | 动作 | 时长 | 参数 |
|---|---|---|---|
| 每 5～8 秒随机一次 | 休休左耳轻抖 | 300ms | rotate ±6°，以耳根为轴，`Curve.EaseOut` |
| 每 7～10 秒随机一次 | 布布右爪轻微内收再伸出 | 400ms | translate y +3vp，`Curve.EaseInOut` |

偶发动作用带随机量的 `setTimeout` 触发，不使用固定间隔，避免机械感。

## 七、叙事动画序列

叙事动画在待机循环之上随机触发，讲述两个角色"在一起待着"的小故事。

**总体调度原则：**
- 同一时间只有一条叙事动画运行，不并发
- 叙事动画结束后进入至少 8 秒的纯待机循环，再允许触发下一条
- 随机权重：动作1（40%）、动作2（25%）、动作3（20%）、动作4（15%）
- 叙事动画触发间隔：上一条结束后 30～60 秒随机
- 所有叙事动画不触发时，仅播放 §6.1 呼吸循环

### 7.1 动作1——「等你发现我」（约 12 秒）

**核心情绪**：布布在偷看，休休慢慢才发现，视线相遇一瞬，然后各自装作若无其事。

| 时间段 | 动作内容 | 技术参数 |
|---|---|---|
| 0 ～ 4s | 静止。布布眼神朝向休休方向（bubu-face-0 侧视版，或 face-1），休休 face-0 直视前方 | 无动画，只是表情切换 |
| 4 ～ 5.2s | 休休头部缓缓向右微转 12° | rotate +12°，pivot 颈部，`Curve.EaseInOut`，duration 1200ms |
| 5.2 ～ 7s | 两者对视停留。休休切换 face-1（好奇），布布切换 face-1（察觉） | 表情切换，opacity 过渡 50ms |
| 7 ～ 8.2s | 休休头部转回。布布右耳轻抖（满足感） | rotate 回 0°，`Curve.EaseOut`；耳 rotate ±8°，300ms |
| 8.2 ～ 12s | 归位。两者恢复 face-0，淡入呼吸循环 | 表情切换 |

**关键节奏说明**：5.2 ～ 7s 的停留段（1.8 秒）是叙事重量所在，不要削短它。

### 7.2 动作2——「困了靠过来」（约 10 秒）

**核心情绪**：休休犯困，不自觉地往布布方向靠，布布默默腾出一点位置。

| 时间段 | 动作内容 | 技术参数 |
|---|---|---|
| 0 ～ 2.5s | 休休眼睛慢慢变为 face-3（困了），头部微微下垂 | face 切换；rotate -8°，pivot 颈部，duration 2500ms，`Curve.EaseIn` |
| 2.5 ～ 3.5s | 休休整体向右倾斜（靠向布布方向） | translate x +4vp + rotate +4°，duration 1000ms，`Curve.EaseInOut` |
| 3.5s | 布布右耳前倾（察觉到了），布布切换 face-3 | rotate +10°，duration 400ms；face 切换 |
| 3.5 ～ 7s | 两者保持轻靠状态，一起缓慢呼吸 | 呼吸幅度加大至 ±2.5%，两者相位接近（同步感） |
| 7 ～ 8.2s | 休休头部弹起（惊醒） | rotate 回 0°，spring curve（response 0.4，damping 0.6），duration 400ms |
| 8.2 ～ 10s | 两者归位，恢复 face-0 | translate 和 rotate 归零，face 切换 |

### 7.3 动作3——「耳朵碰了一下」（约 8 秒）

**核心情绪**：休休右耳不小心碰到了布布，布布反应出乎意料，各自假装没事。

| 时间段 | 动作内容 | 技术参数 |
|---|---|---|
| 0 ～ 1.5s | 休休右耳缓缓向右倾斜，靠向布布头部方向 | ear-right rotate +18°，pivot 耳根，duration 1500ms，`Curve.EaseIn` |
| 1.5 ～ 1.65s | 耳尖轻触布布头部。布布头部轻微 squash | bubu scaleX 0.97 / scaleY 1.03，duration 150ms，`Curve.Linear` |
| 1.65 ～ 2.2s | 布布头部弹回，布布右耳抖一下 | scale 归 1.0，spring；耳 rotate ±12°，300ms |
| 2.2 ～ 4s | 两者出现不同反应：休休切 face-2（小得意），布布切 face-1（"？！"） | face 切换 |
| 4 ～ 6s | 两者同时看向前方，像什么都没发生 | face 切回 face-0 |
| 6 ～ 8s | 休休右耳归位，进入待机循环 | ear rotate 归 0°，duration 800ms，`Curve.EaseOut` |

### 7.4 动作4——「爪爪试探」（约 10 秒）

**核心情绪**：布布的爪子悄悄挪过来，休休的小爪子也出现了，两爪彼此靠近却不接触。

| 时间段 | 动作内容 | 技术参数 |
|---|---|---|
| 0 ～ 2.5s | 布布右爪从右下角缓缓向左平移 | translate x -12vp，duration 2500ms，`Curve.EaseIn` |
| 1.5s | 休休眼神轻微向下偏（察觉到了） | 眼睛位置微移，不切换 face |
| 2.5 ～ 3.5s | 休休左爪从左下角缓缓进入画框 | 新图层 xiuxiu-paw-left 从 opacity 0 + translate x -8vp 进入 |
| 3.5 ～ 5.5s | 两爪停在彼此附近，距离约 4vp，不接触 | 静止停留，呼吸循环继续 |
| 5.5 ～ 7.5s | 布布爪子缓缓收回 | translate x 归 0，duration 2000ms，`Curve.EaseOut` |
| 6s | 休休左爪缓缓退出画框 | opacity 归 0 + translate x 归 -8vp，duration 1500ms |
| 7.5 ～ 10s | 两者看向前方，归位 | 两者恢复默认态 |

**设计说明**：两爪不接触是刻意的。「差一点」比「完成了」更符合「各自忙碌，为彼此留着」的情绪，也让用户感受到悬念而不是结果。

## 八、点击交互——「捏一下」

### 8.1 设计原理

点击交互的目标是「解压且上瘾」，对应真实触觉玩具（硅胶捏捏、泡泡纸）的心理机制：

- **即时响应**：按下当帧必须有视觉反馈，感知延迟需低于 16ms（一帧）
- **过冲（Overshoot）**：弹回时超过原始高度再落回，这个「超出预期」是多巴胺触发点
- **可变奖励**：每次按下效果略有不同（深度/弹幅/音调随机微变），防止腻味
- **永不出错**：无论点多快，动画总能回到正常状态，没有「坏掉」的可能

此交互为纯装饰性，不触发任何业务逻辑，不冒泡，不改变应用状态。

### 8.2 单次点击动效四段规格

```
按下 → [压扁 90ms] → [弹起过冲 190ms] → [二次回调 160ms] → [归位 140ms]
0ms       0~90ms         90~280ms           280~440ms           440~580ms
```

| 阶段 | 时长 | 高度缩放（scaleY） | 宽度缩放（scaleX） | 缓动曲线 |
|---|---|---|---|---|
| 压扁 | 90ms | 1.0 → 0.68 | 1.0 → 1.38 | `Curve.EaseIn` |
| 弹起过冲 | 190ms | 0.68 → 1.18 | 1.38 → 0.88 | `springMotion(0.3, 0.55)` |
| 二次回调 | 160ms | 1.18 → 0.96 | 0.88 → 1.03 | `Curve.EaseInOut` |
| 归位 | 140ms | 0.96 → 1.0 | 1.03 → 1.0 | `Curve.EaseOut` |

**等积补偿原则**：scaleX 与 scaleY 始终反向变化，模拟不可压缩材质（体积守恒），避免角色看起来像是在缩小而不是被压扁。

### 8.3 耳朵独立动画

休休的耳朵比身体**滞后 40ms 响应**，弹起幅度**更大**，创造耳朵「滞后弹起」的二次节奏：

| 阶段 | 相对身体的时间偏移 | 耳朵 scaleY | 说明 |
|---|---|---|---|
| 压扁 | +40ms（滞后） | 1.0 → 0.72 | 比身体少压一点 |
| 弹起 | -20ms（早一点） | 0.72 → 1.28 | 过冲比身体高 |
| 归位 | 与身体同步 | 1.28 → 1.0 | `springMotion(0.25, 0.5)` |

左耳与右耳的滞后再错开 15ms（右耳比左耳先反应），形成耳朵之间的微弱波浪感。

### 8.4 连续快速点击——累积挤压系统

快速连击（上一次点击后 500ms 内再次点击）触发累积效果：

| 连击次数 | 压扁深度（scaleY） | 弹起过冲（scaleY） | 总时长 |
|---|---|---|---|
| 第 1 下 | 0.68 | 1.18 | 580ms |
| 第 2 下（快速） | 0.63 | 1.22 | 620ms |
| 第 3 下（快速） | 0.57 | 1.27 | 660ms |
| 第 4 下（快速） | 0.52 | 1.33 | 700ms |
| 第 5 下及以上 | 0.48（上限） | 1.38 + 左右摇摆 ±5° | 780ms |

第 5 下触发「大招」：弹起后整体左右各摇摆一次（rotate ±5°，每次 180ms），模拟被挤变形后还在抖的状态。

**连击重置**：最后一次点击后 800ms 无操作，连击计数归零。新的第一下永远从基础力度开始。

**中断处理**：新点击可以中断正在进行的弹起动画，从当前 scale 值重新开始压扁。不阻断，不排队，立即响应。

### 8.5 随机微变量（每次点击独立随机）

| 参数 | 随机范围 | 说明 |
|---|---|---|
| 压扁深度 | 基础值 ±3% | 每次手感略有不同 |
| 弹起过冲 | 基础值 ±4% | 每次回弹幅度不完全一样 |
| 压扁时长 | 基础值 ±15ms | 节奏微微漂移 |

用户感知不到具体数字，但会感受到「每次略微不同」，这是防止腻味的核心机制。

## 九、音效设计规格

### 9.1 音效结构

每次点击播放一个复合音效，由两个声音成分叠加：

```
[ 0ms ——  80ms ] 压缩音：软性「噗/咻」，低频为主，像挤压硅胶玩具
[ 60ms —— 380ms ] 弹起音：轻盈「boing」，中高频，音调先升后降
```

总时长约 380ms，比动画（580ms）短 200ms，让最后的归位阶段「无声落定」，不会显得吵闹。

### 9.2 音效文件清单

| 文件名 | 用途 | 描述 |
|---|---|---|
| `sfx_squish_boing_v1.mp3` | 默认音效 | 原调，标准手感 |
| `sfx_squish_boing_v2.mp3` | 随机交替 | 略带混响，避免连续重复感完全一样 |
| `sfx_squish_combo.mp3` | 第 5 下大招专用 | 压扁音更低沉，弹起音有特别的「弹开」感 |

格式：OGG（主）+ MP3（兜底），每文件不超过 60KB，总计不超过 200KB。

建议素材来源：Freesound.org 搜索 `squeeze toy` 或 `stress ball`，选 CC0 授权素材后裁剪至 380ms。

### 9.3 播放速率与音调映射（匹配累积系统）

| 连击次数 | SoundPool 播放速率 | 感受 |
|---|---|---|
| 第 1 下 | 1.00（原调） | 正常 |
| 第 2 下 | 0.92 | 稍低沉，更有重量感 |
| 第 3 下 | 0.85 | 明显低沉，感觉在变形 |
| 第 4 下 | 0.78 | 低沉粘稠 |
| 第 5 下（大招） | 先 0.70 后 1.15（大招音效）| 压扁时低，弹起时突然高起来 |

音调下降模拟真实物理：被挤压越多，振动频率越低。用户不会意识到这个设计，但会感受到「质感正确」。

每次点击在音调基础上再叠加 ±3% 的随机抖动（对应随机微变量系统）。

### 9.4 播放策略

- 使用 `SoundPool`（`@kit.MediaKit`），在组件 `aboutToAppear` 时预加载，`aboutToDisappear` 时释放
- 连续快速点击时，每次点击立即播放新实例，允许短暂叠声（SoundPool 天然支持多实例并发）
- 音量：0.6（60%），不随系统铃声音量变化，只响应系统静音

## 十、震动反馈（可选，推荐开启）

加入震动可将「解压」感从视觉+听觉提升至触觉三重叠加。

| 时机 | 震动强度 | 时长 | 说明 |
|---|---|---|---|
| 压扁时（按下） | 50 | 35ms | 短促的「咚」，接近触觉按键感 |
| 弹起过冲时 | 30 | 20ms | 轻的「弹」，比压扁轻 |
| 第 5 下大招 | 80 | 60ms | 明显震感，配合大招视觉 |

使用 `@ohos.vibrator` 模块，`usage: 'touch'`，触发时机与音效同步（不额外延迟）。

如系统「减少动态效果」开关已开启（`MOTION_REDUCE_KEY` 为 true），震动保留，动画幅度减半（压扁深度最大 0.84，过冲最大 1.08）。

### 12.2 关键动画实现

**压扁+弹起（使用 springMotion）：**

```typescript
private onTap(): void {
  this.updateCombo()
  const depth = this.calcSquishDepth()      // 含随机量
  const overshoot = this.calcOvershoot()    // 含随机量

  // 音效（立即）
  this.playSquishSound()
  // 震动（立即）
  vibrator.startVibration({ type: 'time', duration: 35 }, { usage: 'touch' })

  // 压扁阶段（90ms）
  animateTo({ duration: 90, curve: Curve.EaseIn }, () => {
    this.squishScaleY = depth
    this.squishScaleX = 2 - depth           // 等积补偿
  })

  // 弹起阶段（90ms 后触发，spring 曲线自动完成过冲+归位）
  setTimeout(() => {
    animateTo({
      duration: 490,
      curve: curves.springMotion(0.3, 0.55)
    }, () => {
      this.squishScaleY = 1.0
      this.squishScaleX = 1.0
    })
    vibrator.startVibration({ type: 'time', duration: 20 }, { usage: 'touch' })
  }, 90)

  // 耳朵动画（独立，带延迟）
  this.animateEars()
}
```

**呼吸循环：**

```typescript
private startBreathLoop(): void {
  const breathStep = (): void => {
    animateTo({
      duration: 1400,
      curve: Curve.EaseInOut,
      onFinish: () => {
        animateTo({ duration: 1400, curve: Curve.EaseInOut,
          onFinish: () => { breathStep() }
        }, () => { this.breathScale = 0.985 })
      }
    }, () => { this.breathScale = 1.015 })
  }
  breathStep()
  // 布布延迟 400ms 开始自己的呼吸循环（相同逻辑，独立状态变量）
}
```

### 12.3 技术限制与应对

| 限制 | 应对方案 |
|---|---|
| ArkUI SVG 不支持 SMIL，无法在文件内定义动画 | 全部通过 `animateTo` 从组件外部驱动属性变化 |
| `animateTo` 没有原生 spring 曲线 | 使用 `curves.springMotion(response, dampingFraction)` |
| 多个 Image 表情层叠加切换会有一帧闪烁 | 用 `opacity: 0→1`（过渡 50ms）代替 `visibility` 切换 |
| `squashX / squashY` 无法只对单轴做 scale | `scale({ x: scaleX, y: scaleY })` 分别设置不同值 |
| 耳朵 rotate 需要以耳根为轴心 | 用 `rotate({ angle: x, centerX: '50%', centerY: '100%' })` 设置 pivot |
| SoundPool 首次加载耗时 | 在 `aboutToAppear` 时预加载，不在点击时加载 |

### 12.4 减少动态效果适配

订阅 `MOTION_REDUCE_KEY`（`@StorageProp`），当用户开启系统「减少动态效果」时：

- 待机动画：停止播放，角色保持静止
- 叙事动画：不触发
- 点击交互：保留，但压扁深度最大 0.84，过冲最大 1.08，时长不变
- 音效和震动：不受影响
