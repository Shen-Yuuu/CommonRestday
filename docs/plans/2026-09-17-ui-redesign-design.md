# UI 情感化温度风重构设计

日期：2026-09-17
状态：已与用户逐节确认

## 1. 目标与范围

对 CommonRestday 全 App 做一次视觉与布局重构，方向为**情感化温度风**（情侣同休产品的情感表达优先，同时保持简洁）。

- **核心页全重排**：4 个主 tab（首页/共同/班表/我的）+ 2 个半模态（DayDetailSheet/WindowDetailSheet）按新设计语言重排，交互可重构。
- **编辑页轻改**：课表导入/OCR/循环模板/涂抹/班次编辑 5 页只换色板与基础控件样式，不动布局。
- **不动**：业务逻辑、数据流、领域模型、持久化格式；全部功能入口与操作路径保留。
- **必须保持**：深浅色双模式（沿用 base/dark 双 color.json 机制）、桌面卡片 widget 尺寸约束。

## 2. 设计系统

### 2.1 色板（黄昏体系，以品牌粉为轴扩展）

| 角色 | 亮色 | 暗色 | 用途 |
|---|---|---|---|
| brand_pink（保留） | #D24A7E | 沿用现有 dark 值 | 主操作、选中态、tab 激活 |
| sunset 渐变 | #D24A7E → #E8833A | 深色变体 | 首页主卡、关键强调 |
| page_bg_warm | #FAF7F5 | 暖深灰 | 全局页面背景（替代冷灰） |
| 卡片 | 纯白，去描边，柔阴影 | 对应深色卡 | 层次改用阴影 + 底色差 |
| 功能色 | success/danger/info/warn 保留 | 保留 | 仅状态语义，不做页面装饰色块 |

新增资源均需 base + dark 两份。现有 1px 描边（border_weak）在核心页全部移除。

### 2.2 字阶

问候大标题 28 Bold / 卡片主句 20 Medium / 正文 15 / 辅助 12。

### 2.3 形状与层次

主卡圆角 24、普通卡 20、Chip 与按钮胶囊化；页面水平留白 20；卡片间距 12–16。

### 2.4 图标

全部 SymbolGlyph 系统符号。tab 四枚：house / heart / calendar / person。

## 3. 导航结构（5 Tab → 4 Tab）

- Tab 序列：**同休（首页）/ 共同 / 班表 / 我的**，图标 + 文字，激活色 brand_pink。
- **计划并入「共同」页**：页内分段控件（窗口 | 计划）。PlansView 仅被 Index 引用，合并低风险。
- `navToMe()` 广播目标从 tab 4 改为 tab 3；`navToCoTime()` 仍指向 tab 1。
- 编辑页路由全部保留，仅入口样式升级。

## 4. 页面设计

### 4.1 首页（同休）
- 问候区：按时段问候 + 日期；有伴侣显示「A ❤ B」双方昵称，无伴侣显示单昵称。
- 渐变主卡（sunset、圆角 24、白字）：今晚结论大字主句 + 剩余时长；无窗口显示引导文案。
- 次级白卡：下一个完整同休日 + 出行窗口，两行紧凑卡，小图标点缀。
- 无伴侣引导卡保留（换暖粉底新样式）；底部统计行保留；**删除橙/蓝/绿三色块**。

### 4.2 共同页（窗口 + 计划合并）
- 顶部：月份导航 + 筛选 Chips 保留；其下新增分段控件「窗口 | 计划」。
- 窗口列表行：左侧渐变竖色条（普通粉/周末紫/出行蓝按类型）+ 时间主句 + 标签 Chip + 时长徽标。
- 日历视图、下拉刷新、左滑操作全部保留。
- 计划分段：计划卡片（类型图标 + 标题 + 关联窗口时间），swipe 删除保留；空态改大图标情感化引导。

### 4.3 班表页
- 「我的班表 / TA 的班表」双卡升级：头像占位符 + 来源标签 + 各自编辑入口（图标+名称按钮组）。
- 编辑入口（导入课表/OCR/循环模板/涂抹/班次）保留原路由，按钮卡片化。

### 4.4 我的页
- 顶部个人卡（暖底渐变）：昵称 + 头像占位。
- 伴侣卡：已连接显示双方信息；未连接显示配对引导（QRCode 流程不动，容器升级）。
- 设置项归组为统一列表卡（图标 + 标题 + chevron），参数入口不变。

### 4.5 半模态
- DayDetailSheet：暖底 sheet，三分区 SubHeader 保留；忙碌条配色与暖底协调。
- WindowDetailSheet：窗口信息头加渐变条；「建计划」改大号胶囊主按钮。

### 4.6 编辑页轻改（布局不动）
统一页头（SymbolGlyph 返回 + 20 Bold 标题）；色板映射到新资源；按钮胶囊化、间距统一。

### 4.7 桌面卡片 RestCard2x2
换新色板，widget 尺寸约束不动。

## 5. 明确不做

- Repeat+ListItemGroup 重构（前次已评估取消）
- WaterFlow、bindContentCover、HDS 系 23+/26+ 组件
- 数据层/领域层改动；单测保持 67/67 绿

## 6. 验证策略

每批次完成后：`arkts_check`（改动 .ets）→ `build_project` 全量 → 结束前 domain 单测回归。
