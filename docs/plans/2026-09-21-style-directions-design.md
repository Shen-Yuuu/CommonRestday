# 精简版原型三种视觉气质探索

日期：2026-09-21
状态：用户已确认先制作独立对比页

## 目标

在不修改现有 `docs/prototype/index.html` 的前提下，新建一个轻量风格探索页，让用户以相同内容、相同信息层级，直观比较三种候选气质：温暖编辑感、柔和结构感、深色玻璃感。

## 页面结构

- 顶部说明区：说明这是视觉方向比较，不代表最终功能结构。
- 三个方向卡：桌面端并列，窄屏端纵向排列；每张卡包含同一套“共同时间”手机首屏缩略原型。
- 方案详情：色板、字体层级、组件语气、动效描述与适用性，保证选择依据不仅来自颜色。
- 放大预览：点击方向卡后进入聚焦态，再次关闭返回总览；支持键盘与减少动态效果设置。

## 公平对比原则

三套方案统一展示：日期问候、下一段共同时间、冲突提示、两个次级结论和底部导航。只改变视觉系统与呈现方式，不以内容差异影响选择。

## 三个方向

1. **温暖编辑感**：暖象牙纸面、莓红单一强调色、衬线展示标题、非对称留白和细腻纸张颗粒。适合强调陪伴与生活感。
2. **柔和结构感**：冷银灰底、墨蓝文字、珊瑚橙提示、清晰时间轨道和模块化结构。适合强调效率与可信赖感。
3. **深色玻璃感**：炭黑底、低饱和青绿光、玻璃浮岛与光泽边缘。适合强调科技感和展示冲击力。

## 约束

- 纯 HTML/CSS/JavaScript，不引入第三方依赖。
- 不使用在线图片或网络字体，离线即可打开。
- 不修改现有原型的数据、交互或功能。
- 适配 360px 至宽屏；动画仅使用 `transform` 与 `opacity`，并尊重 `prefers-reduced-motion`。

## 验收

- 三种方案在同一页面可同时比较。
- 点击、键盘 Enter/Space 可放大方案，Escape 可退出。
- 360px、768px、桌面宽度无横向滚动。
- 页面无 JavaScript 控制台错误。
