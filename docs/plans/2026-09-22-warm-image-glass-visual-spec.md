# 「温暖影像玻璃」视觉增强规范

> 状态：已选方向，供后续 AI 直接实施  
> 基线：精简版三 Tab 原型 + 视觉方向 01「温暖编辑感」  
> 参考：用户提供的“背景色/图 + 前景玻璃遮罩”界面截图，仅提取分层与材质理念，不复刻其具体画面、图标或排版。

## 1. 结论

项目采用**温暖编辑底色 + 低对比影像气氛层 + 选择性玻璃层**，不改成全页面毛玻璃。

玻璃只服务于“悬浮、临时、可操作”的前景：底部导航、Sheet、弹层、首页单个关键结果容器。班表、课程、周期和设置等高密度页面继续使用纸面与实色卡片，以保证可读性、性能和深浅色稳定性。

本方向不是给所有卡片加透明度，而是建立明确的三层关系：

1. **气氛背景层**：暖象牙底色之上叠低饱和、低对比、局部聚焦的抽象影像或渐变；
2. **内容纸面层**：正文和密集数据保持近实色，作为稳定阅读基底；
3. **交互玻璃层**：悬浮导航、Sheet 和唯一主结果使用半透明材质，体现“浮在内容之上”。

## 2. 从参考图拆出的可用设计语言

| 层 | 参考图的作用 | 本项目的转译 |
|---|---|---|
| 背景影像 | 提供季节感、情绪和空间深度 | 使用抽象化日光、纸张纤维、柔焦植物色块；不使用高细节人像或可辨识场景 |
| 透明遮罩 | 让背景参与界面但不抢内容 | 首页 Hero、底栏和 Sheet 使用受控透明度；滚动正文不使用实时模糊 |
| 白色雾化 | 压低复杂背景并稳定文字对比 | 在影像和内容之间增加暖白 veil，而不是只依赖 blur |
| 细描边与高光 | 描出玻璃边缘 | 1vp 低透明浅色描边 + 顶部弱高光；不使用厚边框 |
| 低阴影 | 区分前后层 | 大半径、低不透明度的环境阴影；禁用黑色重投影 |
| 圆角分组 | 将内容组成少量大区块 | 保留方向 01 的错角卡片，玻璃层用更连续的圆角，避免所有元素都胶囊化 |

## 3. 页面应用范围

### 3.1 首页：重点增强

- 背景可出现一处静态气氛图层，覆盖顶部至首屏 45%–60%，向下自然淡出；
- “下一段共同时间”Hero 可使用玻璃容器，但文字区下方必须有稳定的暖白/深莓色底，不能直接压在复杂图像上；
- 三个快速答案、冲突提示和今日概览继续使用纸面卡片或近实色表面；
- 首屏只允许一个强玻璃焦点，避免“每张卡都透明”造成层级塌陷。

### 3.2 底部导航：默认玻璃载体

- 视觉上与左右及底部安全区留出呼吸空间，形成悬浮岛；
- 选中态使用浅莓色实心底/光斑，未选中态保持高对比图标与文字；
- 系统材质不可用、降低透明度开启、或性能等级不足时，退化为 92%–96% 的暖白实色；
- 整个导航热区不少于 48vp，不以视觉胶囊大小代替真实热区。

### 3.3 Sheet 与弹层：重点增强

- `WindowDetailSheet`、`DayShiftSheet` 和确认弹层可使用玻璃顶层；
- 表单输入区、时间选择器和危险操作区仍铺近实色子表面；
- 遮罩负责聚焦，玻璃负责层次，两者职责分离；
- 非透明背景色与背景模糊不得无条件叠加。若采用明确实色，则关闭 blur，避免系统渲染结果不可控。

### 3.4 共同时间页：轻量使用

- 列表/周历主体维持纸面；筛选栏可在滚动吸顶后使用轻玻璃；
- 窗口色块必须保持标签、时间和状态对比，不让背景影像透进数据网格；
- 不在 `Scroll`、`List` 或周历每个单元格上应用实时 blur。

### 3.5 我的、日程与录入页：原则上不用玻璃

- 设置表单、班次、循环、课程、涂抹月历以稳定纸面为主；
- 只允许顶栏、底部确认条或临时 Sheet 使用玻璃；
- 表单分组依靠留白、分隔和标题建立结构，不靠多层半透明卡片。

## 4. 设计令牌增量

在 `DesignTokens.ets` 与资源文件集中新增，页面不得写散落常量：

| 类别 | 建议令牌 | 目标 |
|---|---|---|
| 气氛层 | `sceneWarm`、`sceneRose`、`sceneBlue` | 暖日光、莓粉、冷蓝的低饱和过渡 |
| 雾层 | `sceneVeilStrong`、`sceneVeilSoft` | 复杂背景上的稳定对比层 |
| 玻璃表面 | `glassStrong`、`glassSoft` | 分别用于 Sheet/底栏与首页 Hero |
| 玻璃边界 | `glassBorder`、`glassHighlight` | 1vp 描边和顶部弱高光 |
| 阴影 | `glassShadow` | 大半径低透明环境阴影 |
| 动效 | `motionGlassEnter`、`motionSceneShift` | 进入和极轻背景漂移，减少动态时归零 |

初始视觉口径：

- 玻璃表面有效不透明度建议 0.72–0.88；
- 暖白雾层建议 0.28–0.55，随背景复杂度提高；
- 背景图饱和度和对比度均应显著低于内容插图；
- 正文对比按最终合成结果验收，不能只检查资源色值；
- 圆角沿用现有 `radiusCard/radiusSheet/radiusPill`，不另建一套形状语言。

具体数值必须在真机截图对比后锁定；以上范围是实施起点，不是绕过视觉验收的最终值。

## 5. ArkUI / API 26 实现策略

1. **能力探测优先**：API 26 可通过 `@ohos.arkui.uiMaterial` 的 `isImmersiveMaterialSupported()` 判断沉浸材质支持，并读取 `getGlobalMaterialLevel()`；只有支持时才启用系统材质。
2. **双路径渲染**：系统材质路径和实色回退路径必须由同一组件封装，例如 `GlassSurface`，业务页面不自行分支。
3. **图片预处理优先**：背景影像在资源侧完成降饱和、柔焦和压暗/提亮；运行时只做静态缩放与遮罩，不持续计算高半径模糊。
4. **滚动性能优先**：禁止给滚动容器及其重复子项加实时 `backgroundBlurStyle`；玻璃导航与 Sheet 位于独立固定层。
5. **弹层组合约束**：使用非透明自定义背景时设为无 blur；只有半透明材质路径使用 blur/system material，避免两套背景效果互相污染。
6. **降级条件**：系统材质不支持、低性能等级、降低透明度、深色模式对比不足时，统一切换为近实色纸面。

建议新增：

- `entry/src/main/ets/theme/MaterialPolicy.ets`：能力探测、材质等级和用户偏好；
- `entry/src/main/ets/component/GlassSurface.ets`：玻璃/实色双路径容器；
- `entry/src/main/ets/component/AmbientScene.ets`：静态背景图、雾层和渐变；
- `entry/src/main/resources/base/media/scene_*`：经处理的本地资源，禁止运行时拉取网络壁纸。

## 6. 动效规则

- 页面/Sheet 进入仅动画 `opacity` 与 `translate/scale`，沿用 `cubic-bezier(0.22, 1, 0.36, 1)`；
- 背景只允许 8–16 秒周期、2–6vp 幅度的极轻漂移，默认可关闭；
- 滚动时不改变 blur 半径，不做连续视差，不让背景跟随手指高频重绘；
- 底栏选中态用 150–220ms 的位置/透明度过渡；
- 开启减少动态效果时，错峰、位移、背景漂移全部归零；
- 动效不能延迟答案出现、保存结果或错误反馈。

## 7. 可读性与无障碍门禁

- 任何文字下方都必须存在可预测的合成底色；
- 正文、时间、状态和按钮在浅色/深色及最复杂背景处逐一截图验收；
- 状态仍需文字或图标辅助，不能只依靠玻璃色差；
- 触控热区普通模式至少 44vp，底部导航和 Senior Mode 至少 48vp；
- 字体放大时优先增加高度和换行，玻璃容器不得固定高度裁切内容；
- “降低透明度”应得到实色界面，而不是简单移除 blur 后留下难读透明底。

## 8. 实施顺序

### V0：材质基础设施

- 增加令牌、`MaterialPolicy`、`GlassSurface`、`AmbientScene`；
- 用静态 Demo/预览覆盖：系统材质、实色回退、深色、降低透明度；
- 不改业务层级。

### V1：首页与底栏试点

- 只改首页背景、Hero 与底栏；
- 在 360vp 真机/模拟器产出浅色、深色、字体 1.3×、降低透明度四组截图；
- 若掉帧或文字对比不稳，优先减少影像与透明度，不扩散玻璃范围。

### V2：Sheet 统一

- 阶段 2 重构 `WindowDetailSheet` 时接入；
- `DayShiftSheet` 同步使用，但输入区维持实色；
- 统一遮罩、手柄、圆角、底部安全区和进入/退出动效。

### V3：吸顶筛选和宽屏

- 共同时间页仅在筛选栏吸顶后启用轻玻璃；
- 600vp 以上验证背景裁切、双栏内容与浮层边界；
- 未经设备验证不扩展到密集录入页。

## 9. 验收清单

- [ ] 首页同时存在影像气氛、稳定纸面和唯一主玻璃焦点，三层可一眼区分；
- [ ] 底栏、Hero、Sheet 在系统材质不可用时仍完整可用；
- [ ] 360vp、深色、1.3× 字体、减少动态、降低透明度均无截断；
- [ ] 首页连续滚动与 Sheet 展开无可感知掉帧或闪烁；
- [ ] 周历、课程、设置表单没有被改成大面积透明；
- [ ] 截图对比中，背景首先提供氛围，答案仍是第一视觉焦点；
- [ ] 所有触控热区与读屏标签通过设备检查。

## 10. 明确禁止

- 全页面、全卡片统一毛玻璃；
- 在 `List/Scroll/ForEach` 的重复项中实时模糊；
- 从网络随机下载壁纸作为核心界面依赖；
- 在复杂照片上直接放细字；
- 多色霓虹渐变、重黑阴影、过度胶囊化；
- 为追求材质效果牺牲深色模式、降低透明度或低性能设备回退。
