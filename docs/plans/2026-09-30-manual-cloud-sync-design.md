# 云同步失败后手动重试：设计定稿

已由用户确认（2026-09-30）。

正常配对状态维持既有自动同步；首次云同步失败后进入持久的暂停态，不因日切、保存班表、页面重算或下拉刷新自动向云重试。本机编辑和共同时间计算继续使用最后一份有效快照或本机代录，不因云故障失败。

故障只在「我的 → 伴侣与同步」展示。可恢复故障提供「手动重试」，一次点击串行尝试上传本机最新班表和拉取 TA 最新快照；成功后清除故障、重新计算并恢复健康态的自动同步。失败则保留故障和可再次点击的入口；重复点击不能并发发请求。配额耗尽提示额度恢复后由用户手动重试，不承诺自动恢复。鉴权、配对、密钥或版本类不可恢复故障只给修复指引，不给无效重试按钮。

「同休」与「共同时间」移除云同步故障条及只为它服务的页面状态；其他本机计算错误、结果过期和缺少 TA 数据的提示保留。关闭云能力或未配对时不显示重试入口且不发请求。

沿用现有 `SYNCED/RETRY/BLOCKED` 存储格式，旧版 `RETRY` 值升级后也视为手动暂停，不做迁移。同步成功的判定必须覆盖推、拉两段，不能以一次成功掩盖另一次失败。原先的待补删云端配对凭据链路与本次快照同步重试不同，不在修改范围。

验收：离线测试覆盖跨日仍不自动请求、手动重试成功/失败/重复点击、配额和不可恢复错误文案；两档 typecheck 与出包门禁通过。设备上由用户验证失败仅出现在「我的」、按钮真实重试以及同步恢复后的数据刷新。
