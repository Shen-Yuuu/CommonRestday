# 固定标题与渐隐页头

用户已批准直接实施；本轮仅改页面展示，不改数据、同步、导航目标及权限。

- 同休、我的：单一固定标题，滚动 0–96vp 时由大标题逐渐缩至 82%；标题几何高度不随滚动变化，避免滚动偏移与布局重算互相追逐。减少动效时保持原尺寸。
- 同休保留问候语、伴侣状态和日期；我的新增页面标题，原身份摘要及详情入口全部保留。
- 共同时间：现有标题、列表/周历/计划三段及筛选不移动；列表和计划滚动内容顶部使用 24vp 渐隐边缘，周历使用 12vp。停在顶部时隐藏，滚过 0–24vp 才逐渐显示；计划遮罩放在实际 List 上，不遮计划操作行。
- 日程录入：返回、我/TA、周历/日程管理固定在顶部，正文仍可滚动及下拉刷新，滚动区域使用 24vp 渐隐边缘，静止顶部时隐藏。
- 2026-10-01 第二次截图反馈后修订：移除矩形系统背景模糊。标题与下沿改成单一连续底色渐变，标题区域保持清晰、下沿在 36vp 内透明渐隐。使用现有浅色/深色资源，不混入下方 Hero 的粉色，也不称其为连续渐变背景模糊。
- 周历 Scroll 具有明确的剩余视口高度；底部 dock 留白放进滚动内容，不扣减视口。内容超出时可上下滚动，内容较少时仍允许下拉刷新。
- 渐隐层不拦截点击、不进入读屏；页头按实际内容量高，保留系统大字体换行，不硬截副标题。
- 第三次反馈修订：`overlay` Builder 最外层使用有明确高度的原生 Row，并配置 `HitTestMode.Transparent`；内部渐变仍为 `None`。共同列表/周历、计划、班表四个覆盖入口统一处理，不能只靠内部组件的禁命中。
- 周历日期范围、前后周和「本周」合成一排；纵轴与更新状态共用小字行，删除常驻的空白加载占位，行间距收为 4vp。保留 44/48vp 按钮热区；日期表头可点击，共同模式计算范围外的日期仍不开放。
- 周历加载不禁用整个组件；两种异步读数用当前请求令牌在 finally 中收尾。切周、日期和滚动保持可用，仅加载中/失败时不使用旧空闲块发起计划。
- 编辑器、课程录入、详情面板和隐私页面不改。

设备验收交用户执行；本机只做静态、离线及构建验证，不操作模拟器。
