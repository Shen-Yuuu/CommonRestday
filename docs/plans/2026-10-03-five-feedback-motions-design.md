# 五项局部反馈动效定稿

日期：2026-10-03。依据：用户逐条确认的五项动效；不以先前概括中的导入动效替代。

1. 今日安排：前三条常驻，多余条目在局部裁剪容器中约 180ms 展开/收起；同一个进度驱动箭头 0–180°，快速反向点击从当前位置接续。测量的是列表内容，不是页头。
2. 分享等级：旧项立即撤去底色，只有新选中项约 140ms 进入底色。文字、热区、持久化与共享逻辑不变。
3. 新建计划：仅创建成功才发布一次性的内存提示。关闭起草器后进入共同页的“计划”，按真实计划 id 定位；新条目短暂品牌色高亮后恢复。不改排序，不用重新读整页制造闪动，失败不高亮。
4. 周历：前一周从左侧、后一周从右侧进入，约 220ms。周导航仍能响应连续点击；数据落地以后再让网格进入，旧请求/旧动画不允许覆盖新周。仅位移与透明度参与动画，不给父页标题或网格高度加动画。
5. 手动同步：点击位置的原生按钮显示“同步中…”及等待指示，结束后在同一个位置显示真实结果。重复点击被拦截；不能用动画结束冒充同步成功，不能额外触发云请求。错误说明仍只在“我的”。

范围边界：不新增导入动效，不新增“减少动态效果”设置项，不改现有数据/云协议，不操作模拟器、不部署云资源、不提交混合工作树。已有系统级动效偏好保持原状，不增加用户操作。

实现以本机 API 26 SDK 的 UIContext.createAnimator / AnimatorResult、Scroll.enableScrollInteraction、Scroller.scrollToIndex 签名为准。帧动画用途亦见[华为官方文档](https://developer.huawei.com/consumer/cn/doc/doccenter-capabilities/arkts-animator)。设备观感必须独立验收，编译与静态检查不能代替。
