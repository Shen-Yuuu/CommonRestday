# 作息设置与系统调色直达设计

日期：2026-10-03。用户已确认作息面板方案，并要求自定义颜色不再经过中间面板。

## 作息设置

- 保留贴底面板，目标高度约屏幕 46%，不改成全屏设置页（收到实测反馈后由 40% 上调）。
- 标题使用清晰的粗体，上方留白 20vp（原 8vp），标题、正文和操作区间隔 10vp。
- 起床、就寝并排：小标签在上、时间在下；点击打开系统时间选择弹窗，采用 24 小时制。
- 睡前准备、往后计算放入同一组，两行排列；单位写进左侧标签，两个数字输入框在行末使用相同宽度 80vp、零水平内边距和右对齐，不再有数值右侧的单位列。
- 最短共同时段默认三个紧凑选项：1小时、2小时、4小时，位于标签右侧。选中项用浅粉底、深色字。历史非标准值继续显示，窄屏与大字体时允许选项区换行。
- 取消、保存固定在底部，底部额外留出空间；正文可滚动以容纳键盘、小屏与大字体。
- 所有输入仍是草稿，保存继续走原服务校验与重算；取消、滑动关闭均不写入。历史自定义最短时段不被强制归入三档。

## 自定义颜色

- `HdsColorPicker` 直接放在班次颜色预设末尾，点击其系统按钮直接打开系统调色窗口。
- 所有颜色占用 44×44vp 布局格。自定义颜色放在显式居中的 Stack 内，内部系统按钮 26×26vp，与预设圆直径相同；不要把系统按钮的外框直接拉到 44vp，否则内部圆仍可能停在左上方。
- 删除应用内的“自定义颜色”中间页、“返回 / 使用此颜色”按钮与对应临时状态。
- 系统 `onColorSelected` 回调只更新当前班次编辑草稿；保存班次才写库。关闭班次编辑器仍不保存。
- 初始颜色随打开班次、点击预设色、确认自定义色更新，不额外叠加点击拦截层，也不调用未公开的控制器。

## 接口依据与证据边界

本机 API 26 SDK 的 `@hms.hds.HdsColorPicker.d.ets` 提供 `HdsColorPicker`、`initialColor`、`onColorSelected`、`circleRadius` 和三个调色页签；没有公开的 `show()` 控制器。直接使用该组件的原生入口。

时间选择使用 `UIContext.showTimePickerDialog`，仅 `onAccept` 更新草稿，取消不更新。

本轮仅运行源码接线检查、离线测试和本机构建。不操作模拟器；系统调色的取消行为、返回编辑器后的草稿、面板高度与键盘避让，由用户在设备验收。不能把编译通过写成触摸和视觉已通过。
