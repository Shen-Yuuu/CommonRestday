# 首页与设置交互精简设计

日期：2026-10-03。用户已同意上一轮方案：实施反馈、首页日程、设置精简、计划配色与随机粒子（原请求 1–8）；课程导入与其他联动动画（9–10）仅设计，不开发。

## 范围与约束

- API 26；保持现有 Navigation/HdsTabs、读模型、SettingsStore 与权限链路。
- 不操作模拟器或手机，不部署云对象、不清数据、不改签名、图标、隐私政策或共享协议。
- 当前工作树存在大量用户/其他 AI 改动，仅在必要位置增量修改，不提交整片工作树。
- 设备闪烁的原因尚属推断，源码和离线门禁通过不代表渲染验收通过。

## 反馈

Dock 直接切页，不用全局 animateTo 包裹页签和页面状态；关闭页签内容的切换动画。图标和选中底色仍表示当前页，只有按下项做轻微缩放，不加暗色遮罩。本机 HdsTabs 未发现单独关闭原生按压层的属性，采用 TouchEvent.stopPropagation 隔离触摸冒泡，并关闭自制条目 hover；不猜造 API。此处理是否彻底去掉设备上的暗闪仍待用户验证。

答案行按下立即显示浅底，松开一次短淡出；移除两个重叠 animateTo。一次点击只调用一次原有回调；打开 sheet 期间加入口闩，避免连点重复打开。

## 今天安排

在空闲摘要和操作按钮之间放时间轴。只展示我的班次、课程、本机保存的计划；不读取或展示 TA 的私有标题与精确课程。按开始、结束、稳定 ID 排序，筛选与今天有真实交集的安排，排除零长/无效区间和恢复缓冲。展开读取从昨天开始，保留昨晚开始的夜班；按现有班次区间显示，配置通勤的班次标注「班次·含通勤」。跨天明确标记昨晚/明天，结束零点沿用 24:00 口径。空列表隐藏；超过三条可展开/收起。只在本地查询，不额外调用云端。查询失败显示可理解的本地读取失败说明，不把失败说成没有安排。

## 我的与详情

身份卡单人标题改为「单人模式」，删除副文案。伴侣与作息摘要卡整张可点击，删掉管理/设置按钮；云同步提示仍在我的页，手动重试不冒泡打开详情。

伴侣详情：标题改为「本机代录」「云配对」，删除对应解释段，保留按钮和状态/错误提示。共享选项显示「忙闲状态」「班次类型」「完整时间」，去掉 Radio 和代号，选中背景表达选择，同时设置可访问的选中语义。说明分别为「TA 看得到你有空还是在忙」「TA 看得到你在做什么」「TA 看得到你完整的忙碌时段」。数值与持久化逻辑不变，未知等级保持无选中状态。

作息详情：底部 sheet 为 38% 屏高，去掉嵌套卡片与多余查看/编辑层；打开即编辑临时草稿。起床/就寝并排，睡前准备/往后计算并排，最短时段直接显示，保存/取消固定底部。键盘与大字体时正文可滚，不缩小操作热区。取消/关闭恢复保存值。伴侣详情按未配对/已配对/编辑与输入状态采用合适高度，内容溢出可滚动。

## 配色与粒子

普通计划的周历色从固定绿色换成莓粉，冲突保留警示色，班次自选色不变。首页计划标签用主题资源，不硬编码前景白色。

每颗粒子保留原周期和上升距离（纵向速度不变），每轮随机出生位置、横向漂移、等待间隔。粒子到透明时才重置，数量/尺寸/亮度不增加。使用可取消 animator，后台、减少动效、组件销毁，以及栈目的地或 router 页盖住 Dock 时取消，前台可恢复。纯参数算法可离线测试，不做定时常驻服务。

## 后续提案（本批不实施）

1. 文件导入：先 CSV/Excel 标准模板，再支持字段映射及周课表矩阵。文件选择→解析→预览逐项纠错→确认写入；重复项默认跳过，禁止静默覆盖。首期可先支持 CSV 与表格粘贴，XLSX 需先评估 ArkTS 兼容解析方案和包体。
2. 表格粘贴：支持制表符多列而非只支持固定中文句式，复用文件导入预览。
3. ICS：处理时区、重复规则、例外日期后再接到现有模型；不能把一次事件无损伪装成学期课程。
4. 学校网站：明确选定学校、用户在系统/受控页面登录、本地解析预览；不收集学校密码到开发者后台，不绕过验证码，不承诺通用适配。
5. 有意义的动效：今日列表展开、共享选择、新保存计划短高亮、周历水平翻周、同步按钮状态过渡。禁止把旧的滚动缩放标题回潮，禁止全页模糊/尺寸回弹。

参考：华为 [文件选择器](https://developer.huawei.com/consumer/en/doc/harmonyos-references/js-apis-file-picker)、[前台绘制渲染建议](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V13/standard-foreground-render-V13)、[RFC 5545](https://www.rfc-editor.org/info/rfc5545/)。这些是方案依据，不表示已集成文件导入。

### 9 · 更好的录入：先降低重复输入成本

下面是针对当前「班次 + 学期课程 + 临时调整」模型的产品建议，不是已经实现的功能。

| 建议顺序 | 入口与体验 | 价值与边界 |
| --- | --- | --- |
| 第一批 | 在课程页「批量导入」里选择「粘贴表格」或「CSV 模板」；提供可复制的示例行 | 几乎所有表格工具能复制制表符文本或导出 CSV；先不承担 XLSX 压缩容器、公式和合并单元格的解析成本 |
| 第二批 | 「Excel 文件」先选工作表、识别表头、手动映射列，再预览 | 不只支持本应用模板，但不能承诺任何课表截图样式都能自动理解；需本机 SDK 构建验证解析器兼容性、包体和内存 |
| 第三批 | 学校白名单导入，明确列出支持的学校和系统版本 | 用户仍自己登录教务网站；不收集密码、不绕验证码；先覆盖目标用户最多的学校，避免不稳定的“支持所有学校”入口 |
| 独立后续 | ICS 文件/日历交换 | 适合日程与重复事件，未必适合按节次的学期课程；模型无法表达的重复/例外不静默截断 |

所有来源汇入同一个确认页面，而不是导入就落库：

1. 选择归属「我 / 本机代录的 TA」；云配对对方的日程不开放写入。
2. 显示已识别条数、待修条数、重复条数。每行可改课程名、星期、节次、起止周、单双周；缺学期起始日期或节次表时先补齐。
3. 检测重复，以来源归属 + 名称 + 星期 + 节次 + 周范围作为候选匹配；默认跳过完全重复项，明确区分同名不同时间的课程。
4. 无法识别的单元格保留原文，定位到行/列；不猜一个时间直接提交。明确告知“导入 N 条，跳过 M 条”，一次确认只重算一次。
5. 保留撤销本批导入的设计，但不能用“删掉所有同名课”代替精确批次回滚；实施时需先确定批次记录模型。

建议模板字段：`课程名、星期、开始节、结束节、起始周、结束周、单双周`，示例为 `高等数学、周一、1、2、1、16、每周`。时间型表格可以另选 `开始时间、结束时间`，转换不可靠时提示改用按时间的安排，不能硬塞成不存在的节次。

文件入口采用系统 DocumentViewPicker，由用户选择文件；选取 API 不负责解析 Excel，解析是另一项工作。[华为文件选择器文档](https://developer.huawei.com/consumer/en/doc/harmonyos-references/js-apis-file-picker)。ICS 导入需要正确处理时区、重复和例外日期，不能仅拆 DTSTART/DTEND。[iCalendar 标准](https://www.rfc-editor.org/info/rfc5545/)。学校支持范围和解析库选择均为后续调研，当前没有已验证名单。

### 10 · 值得增加的联动动画

优先让用户看清“发生了什么”，不让每张卡都常驻晃动。以下时间为待试用的设计值，不是已验收的性能结论。

| 场景 | 建议 | 本批状态 |
| --- | --- | --- |
| 今日安排展开 | 160ms 局部淡入；已有行保持位置连贯，不重新播放整页入场 | 已接入，待设备 |
| 保存计划成功 | 新行一次 200ms 淡入 + 约 600ms 浅莓高亮后归位；保留文字成功提示 | 仅方案 |
| 切共享范围 | 选中背景在同组内 140ms 过渡，不改变行高，不另加勾选图标 | 仅方案 |
| 翻周 | 周历内容按方向短距离平移，日期与内容一同换；置顶栏固定，不对 Scroll 的测量高度做动画 | 仅方案，先守住现有交互/闪烁修复 |
| 手动同步 | 只有正在请求的按钮显示进度；完成后一次状态更新，不用全页骨架遮掉本地数据 | 仅方案，复用真实请求状态 |
| 表格导入 | 文件进入预览后逐组揭示校验结果，错误行定位不依靠持续闪烁 | 随导入功能一起考虑 |

统一边界：减少动效时直接切状态；切页不让旧/新两项同时“按下”；不把云请求完成时间伪装成固定长度动画；不让模糊、随机运动或放大缩小影响正文可读性。Dock 随机粒子是装饰例外，本批已补后台/覆盖停止，但仍需设备检查实际耗电与帧率。
