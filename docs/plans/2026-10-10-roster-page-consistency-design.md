# 周班表页面一致性

本次界面需求由用户明确指定：日程管理的周历 Tab 改为「我的班表」；周班表沿用现有班次、课程页面的顶部布局，左侧粉色箭头加返回文字，中间唯一标题，右侧常用班次入口。正文删除重复标题和入口。保留保存中与未保存草稿的返回保护。

周班表与已有日程／共同周历共用 WeekNavigator：左箭头、居中日期范围、右箭头、本周按钮。沿用现有颜色、字号、44vp 热区与读屏标签。周历已有水平动画仍由父组件传入偏移和透明度，导航组件不改变标题高度或异步加载逻辑。

计算诊断：CommonFreeEngine.buildAvailability 在 weeklyMode 为真时给每个 UNKNOWN 日期添加整日忙碌，因而空白周没有共同空闲。用户已选择「改为未安排不占用时间」。删除这份人工整日占用，作息、通勤、课程、个人安排、已确认计划与跨日恢复仍使用已有口径。UNKNOWN 与 REST 的存储状态继续区分，以保留排班与复制语义；不将尚未拿到 TA 数据的情况默认为共同空闲。

引擎、快照与共同计划本机可用性检查均复用同一 buildAvailability。新规则版本与窗口缓存同事务写入，旧规则缓存时间读为 0 以触发现有首次加载的重算，不删除排班或配对。两端覆盖更新后通过下拉／手动同步交换新快照；旧版 TA 快照的整日占用不能擅自过滤，因为可能已按隐私等级降维且无法区分来源。

保留所有排班、旧模板、课程、个人安排、计划与配对数据；不安装或清模拟器数据、不部署云端。
