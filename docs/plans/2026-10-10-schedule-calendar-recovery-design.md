# 班表入口恢复与空窗口修复

用户要求：恢复我的班表周历；周班表只在日程管理内进入；常用班次只从周班表右上角进入。新排班的数据模型继续使用，不退回旧循环序列，也不删除已保存记录。

入口为「我的 → 班表与课程 → 周历／日程管理」。周历使用已有 WeekScheduleView 日程模式，点日期复用 DayShiftSheet；日程管理仅保留周班表、课程表。周班表通过既有 CycleEditor 路由打开，保留其草稿与保存保护。

空窗口根因：replaceWindows([]) 成功后没有窗口行，windowCacheComputedAt() 用 MAX(computed_at) 得到空值，误判为从未计算。将计算完成时间记录在 sync_meta，和窗口批次在同一事务写入；读取兼容旧版本行时间。零窗口也是有效结果，真正未计算或过期仍保留重算提示。

周历切换崩溃：当前模拟器两份应用 JS 异常中，切换动画调用 CoTimeView.commitView()，空列表的 Scroller 未绑定，currentOffset() 返回 undefined，读取 yOffset 抛错。安装的 API 26 声明也说明这一返回行为。改用 SDK 明确可空的 Scroller.offset() 并保护缺省／非有限值／控制器脱离时的异常；保留上一次滚动位置和原切换动画。

只读读取设备日志，未存储原始异常文件、业务内容或凭据；不安装、不清设备数据、不部署云端。验证用隔离 SQLite 执行生产仓储，覆盖空结果、旧版本读取、事务失败回滚；用生产滚动辅助函数覆盖未绑定与异常情况，并进行两种云开关离线验证及 Debug 构建。
