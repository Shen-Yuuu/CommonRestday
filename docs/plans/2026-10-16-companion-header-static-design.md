# 共同休时双角色静态预览

用户已选择标题右侧双角色互动方向，并同意先确认静态形象和占位、之后再做分层动作。这一轮不接入正式 App，不制作循环或计划成功联动。

## 视觉定稿范围

- 延续现有布布（暖杏小熊）与休休（白色长耳兔）的平涂矢量语言、深棕五官、暖棕/粉色轮廓；并肩坐着、头略靠近、内侧小手轻碰。无底框、背景和组件投影。
- 独立 SVG viewBox 224×128；角色组、耳朵、身体、眼睛、手臂分别命名，方便后续按已批准方向继续分层，不宣称当前已经可直接运行 ArkUI 动画。
- 预览标题「共同休时」，副标题「TA · 未来 4 个月」；角色占位 112×56 CSS px，标题与角色共处原页头一行，列表/周历/计划保持下一行。
- 页面用现有粉色/奶油白/深棕体系；桌面只做静态评审页，包含手机实际占位、放大造型、深浅背景和窄屏检查。示例日程明确为演示数据。

## 技术边界

根据 imagegen 技能适用范围，扩展项目原有 SVG 插画体系优先保持代码原生矢量，不改成生成位图。本批仅新增 docs/prototype 下的预览文件，不修改 entry、feature、cloud 或旧素材。

通过 agent-browser 的独立本地会话渲染检查和截图；浏览器截图只是 HTML 构图预览，不是真机 ArkUI 运行截图。没有新增依赖、读取个人数据、提交或发布。
