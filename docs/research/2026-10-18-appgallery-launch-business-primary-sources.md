# 两人份：AppGallery 上架与商业化一手资料核对

调研任务基准日：2026-10-18（Asia/Shanghai）；检索期间客户端日期更新至 2026-10-19。只读查阅华为、政府正式资料；没有登录开发者后台，没有修改业务代码或云端。本文不是本应用已完成／未完成项的验收结论。

## 结论先行

- 普通工具应用的个人开发者身份与“可以接入内购”不是同一资格。最新商户服务 FAQ 存在个人支付 SDK 限制，但没有在该句明确区分 HarmonyOS IAP Kit、旧 HMS 应用内支付与独立支付通道。本文不能据此一概判定本应用个人主体不能收费，也不能据“能开通个人商户服务”保证能做 IAP 订阅；实际资格待核实。
- 先完成免费版本的备案、隐私、生产签名、真机全链路验证和商店材料；这些比接入收费优先。商业化增加交易、退款、恢复购买与权益归属工作，不是仅加按钮。
- 当前公开官方资料能证实 IAP 的永久非消耗型与自动续费订阅能力，不能据此替本账号保证服务准入、费率或中国大陆付费下载开通成功。

## 1. 上架资格与备案

华为开发者服务协议将个人、法人及其他组织纳入开发者定义，并要求完成在线实名认证。没有根据可以笼统说普通日程工具必须先成立公司。应用类别特定资质仍应对照最终上架分类逐项核验；不要把情侣协同工具自动等同于婚恋交友平台。[华为开发者服务协议](https://developer.huawei.com/consumer/cn/devservice/ServiceAgreement/)

工信部要求在中国境内提供互联网信息服务的 APP 主办者履行备案手续，未备案不得提供相应服务；新开展业务应先备案。云端免费额度、仅双人配对、无手机号码登录都不等于免备案。备案号展示、主办者、包名和网络资源信息需要按备案实际资料核对。[工信部 APP 备案通知，工信部信管〔2023〕105 号](https://www.miit.gov.cn/zwgk/zcwj/wjfb/tz/art/2023/art_920db564162e4312916a01bed6540ad8.html)

本次没有确认本应用备案号、软著或电子版权认证状态；不应把软件著作权直接写成所有工具必需，也不应保证本项目一定豁免。[华为应用资质审核要求入口](https://developer.huawei.com/consumer/cn/doc/app/80301) 正文在本次抓取中未完整返回，请在提审后台确认实际所需材料。

## 2. 隐私政策、匿名认证及删除

使用 AGC 认证 SDK 时，官方要求以开发者自身名义提供独立隐私政策，首次处理个人信息前醒目提示，SDK 使用前取得同意或其他合法基础，并如实披露第三方 SDK。指南要求支持访问、更正、删除等权利，并提供 `Auth.deleteUser` 接口；其 `Auth.init` 需在取得用户同意后调用。[认证 SDK 合规使用指南，更新 2026-10-13](https://developer.huawei.com/consumer/cn/doc/doccenter-operations/agc-help-auth-personal-data-0000002236337034)

对本产品的检查建议（由上述要求推导，不是华为对本产品的逐项判定）：

- 匿名认证不应表述为“绝不产生云身份／个人信息”；说明匿名 UID、配对绑定、同步密文、设备推送标识的实际用途和保存期限。
- 本地“清空”或“解除配对”不一定等于云端删除。逐项验证删除入口能否处理认证身份、绑定、计划密文、通知设备绑定；依法必须保留的安全／交易证明应说明范围、期限及处理方式。
- 用户不使用云配对时，不应为便利而提前启动无关身份或推送收集。

上述是待验收清单，并非断言现有代码没有实现。还需按实际 Cloud Foundation Kit／Push Kit 接入版本的官方 SDK 声明填写，不能照抄别的 SDK 数据清单。

华为官方分发介绍要求如实填写应用隐私声明，允许使用标准化隐私声明托管服务；不等于所有原生 App 都必须使用托管。商店隐私链接、App 内文案、实际处理行为应一致。[在应用市场分发](https://developer.huawei.com/consumer/cn/appgallery/devstart/)

## 3. 发布包、通知与商店材料

Push Kit 官方明确：发布阶段申请发布证书，确认推送已开通后重新申请发布 Profile，并手动签名。调试设备上能收到推送，不代表发布签名包已完成同样配置。[开通推送服务，更新 2026-07-28](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/push-config-setting)

本地通知不能替代离线 Push：官方说明应用转后台后本地发布通道关闭，离线通知需要 Push Kit。[Notification Kit 简介](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-v5/notification-overview-V5)

工作提醒权益使用建议：只用于用户主动创建／确认的共同计划相关事务；不要混入优惠、拉活、会员促销。权益通过并不等于通知必达，需验证通知权限、锁屏、后台／被结束、深链打开以及重复通知。具体批准的类别、审核示例与发送参数必须保持一致。本次只确认了官方要求按对应自分类发送的规则，未完整取得当前“工作事项提醒”分类表正文，不额外扩大其适用范围。[Push 配置与自分类要求](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/push-config-setting)

华为提交入口要求正式提交前完成安全、隐私、兼容、稳定和性能测试，并准备图标、截图、介绍等资料。具体尺寸以提交页当前要求为准，不采用论坛中的固定尺寸或审核时长承诺。[提交 HarmonyOS 应用](https://developer.huawei.com/consumer/cn/app/submit)

建议给审核人员准备一段清楚的双端流程说明：设备 A 生成短码、设备 B 加入、双方确认配对、A 邀请、B 同意、双方计算变化、取消与断网重试；如需账号，提供可用测试条件。无日志调试和自动化测试不能替代真实发布包上的这条验收链。

## 4. 商业化可用形式与准入

### 可确认的平台能力

IAP Kit 官方当前产品页明确支持消耗型、非消耗型和自动续费订阅；非消耗型一次购买不过期，自动续费取消后当期结束不再续期。适合讨论一次性本地高级功能与持续云服务订阅，但具体商品还需准入和审核。[IAP Kit 官方产品页](https://developer.huawei.com/consumer/cn/sdk/iap-kit)

华为正式分发路径说明，提供数字商品需先开通商户服务并签署《华为数字商品及联运服务协议》，支持先做沙盒交易测试。[数字商品分发前置条件](https://developer.huawei.com/consumer/cn/appgallery/devstart/)

最新《开通商户服务》FAQ 直接说明“个人不支持接入支付SDK”。但该句未明确区分本项目的 HarmonyOS IAP Kit、旧 HMS 应用内支付与独立支付通道，因此不能推出“中国大陆个人 HarmonyOS 工具一概不能收费”。同页有个人商户开通指引，商户与特定能力准入应分开判断。应在实际应用的 IAP Kit／数字商品开通页确认，必要时提工单注明平台、地区、主体与商品类型；若受限再确认企业主体方案，不以“打赏”外链规避。[开通商户服务，更新 2026-10-13](https://developer.huawei.com/consumer/cn/doc/doccenter-getting-started/hdc-merchant-service-0000002752616107)

官方账号 FAQ 不支持个人与企业账号类型直接变更；可用新主体认证新账号，再按流程申请应用转移。所以收费前确认主体，可减少后续迁移成本。[开发者账号 FAQ，更新 2026-10-13](https://developer.huawei.com/consumer/cn/doc/doccenter-getting-started/hdc-account-faq-0000002733714632)

### 付费下载与费用的不确定项

HarmonyOS 5 及以上消费者文档提及付费下载应用，证明平台存在这种形态；不证明本应用当前账号可以直接选择或无需额外申请。[消费者应用内支付说明](https://consumer.huawei.com/cn/support/content/zh-cn16010480/)

本次没有可靠核实适用于本账号／本应用／地区的抽成、税费、结算周期和优惠政策。不引用网上通用“15%／30%／零抽成”。成本模型先把平台费用设为变量，最终根据实际签署协议和结算单计算；AGC 云资源费与内购收入分成是两个不同账目。

没有找到普通原生工具 App 所有数字功能只能使用 IAP 的完整当前强制条款；不能移植苹果规则或元服务规则。建议采用华为官方 IAP 路径并让平台确认实际交易设计，也不据此保证外链支付一定允许。

## 5. 自动续费额外要求

国家网络交易规则要求服务前和自动续费前五日显著提醒，用户自主选择，并提供显著、简便的随时取消或变更选项，不收不合理费用。不能默认勾选、隐藏取消入口。国家条例的“续费日前提醒”与部门规章“五日”应分清，不能把“五日”误写为条例原文。[广州市委网信办收录广州互联网法院正式法条与案例说明](https://www.gzwxb.gov.cn/context/contextId/213401)

产品实现建议：收费页明示权益、适用两人还是一人、价格、周期、到期／续期、取消、退款与客服；服务端验证交易并处理补单、恢复、退款撤权。尤其应定义解除配对／更换伴侣时“谁拥有付费权益”，不应假设华为自动处理情侣共享。

## 6. 商业策略建议（不是政策或市场验证结论）

首版先免费邀请测试，稳定双端、离线、恢复与删除链路，验证“双方都愿意持续录入日程”的留存。免费保留基本排班、配对和计划确认，避免在最需要对方参与的一步收费。未来可把高级排班效率、更多样式／角色、统计／导出等作为付费候选；持续云服务定期收费比永久承诺无限云容量风险更低。暂不推荐开屏／强插广告侵入情侣工具核心流程。

本次没有做竞品收费和付费意愿研究，因此不把某个年费数字或转化率当成结论。正式定价应在主体准入、实测每活跃配对成本和真实留存数据确定后，用少量清晰套餐验证。

## 证据边界

不使用开发者论坛普通用户回复、第三方镜像、旧 Android HMS 接入 API、苹果政策作本结论的依据。部分正式文档页面只返回框架／超时，已明确标为未核实。当前项目完成程度须另由仓库与后台／真机证据审核；本文件只提供官方门槛与商业策略边界。
