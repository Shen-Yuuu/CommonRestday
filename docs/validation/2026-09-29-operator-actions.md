# 下一轮需要开发者本人完成的动作（2026-09-29）

当前已完成无设备代码、离线测试与出包验证；下列步骤不由构建成功替代。**不要清空、卸载或在 5555 上运行全量 ohosTest。**

## A. 准备独立测试设备

1. 在 DevEco Studio 的 **Tools → Device Manager** 新建两台 API 26 手机模拟器，命名成明显的“可丢弃测试 A／B”。不要克隆 5555 的已有数据；两台都从干净应用数据起步。系统镜像、SDK 和模拟器实例是不同位置，不需要为了创建实例搬动现有 SDK。参考：[华为模拟器管理文档](https://developer.huawei.com/consumer/cn/doc/doccenter-deveco-studio/ide-emulator-create)。
2. 启动 A、B，确认 Device Manager 和 `hdc list targets -v` 同时显示两台 **Connected**。只把目标端口／设备名发回来，不发设备日志、完整 pairId、密钥或签名材料。若电脑只能同时运行一台，先告诉实施者内存／硬盘限制；不能改用 5555 凑第二台。
3. 用测试身份在 A、B 建立**与 5555 无关**的测试配对。再跑 AO 设备计划的云删失败／成功、回前台补删、终局拒绝、HUKS 卸载与全量 ohosTest。凡会改 AGC 配额或已部署对象的失败注入，先用独立测试资源和测试 pair，不能在正式 pair 上试。设备操作与证据由实施者接手，不必现在自行删除任何数据。
4. 协议 §11 的“第三台拒绝”需要再临时启动测试 C；A／B 不够时这格保持未验。A／B 跑完后记录 app 版本、目标端口、测试时间、结果和脱敏的 pairId 指纹，再决定是否清理这两台可丢弃实例。

## B. 现有 5555 只做可逆观感确认

1. 记下当前显示模式（应为浅色）、共同时间页选中的筛选项和横向滚动位置；不要按业务保存键。
2. 打开共同时间页，系统设置切深色，再回到应用：看五颗筛选 Chip 的字／底是否**当场**变成深色档，同时胶囊与页面背景同步换档，筛选项不跳回“全部”。
3. 保持深色，冷启动应用，拍同一页；把这张与实时换档后的 Chip 对照。七页深色冷启复拍也可在 5555 完成，但只浏览页面，不改业务数据。
4. 系统设置切回原浅色，核对共同页颜色、原筛选项和配对状态；把前后截图发给实施者。D-65 在这一组画面过关前仍为“代码／构建通过，设备待验”。

## C. 账号／商店侧

1. 将 `docs/legal/privacy-policy.html` 放到你控制的稳定 HTTPS 地址，用未登录／无痕浏览器确认能打开、全文可读；逐项对照包内全文与 `docs/legal/privacy-policy.md`，不要把旧“无 INTERNET／云端未开放”版本上传为当前政策。把最终 URL 交给实施者回填和复跑 `copy-audit`。华为应用审核说明要求提交链接的内容与 App 内政策一致：[隐私政策审核说明](https://developer.huawei.com/consumer/jp/doc/app/FAQ-faq-09)。
2. 在 AppGallery Connect 核对当前应用的包名 **`com.common.fortwo`**、展示名“两人份”、开发者主体、`vendor`、备案／资质状态与现有云资源归属。备案是否必需以当前应用业务、服务所在地和审核界面要求为准；不要仅凭仓库里“待备案”字样推断已完成或豁免。记录**状态和待办项**即可，不把个人证件传到聊天或仓库。参考：[华为提交应用指引](https://developer.huawei.com/consumer/cn/app/submit)。
3. 为正式发布准备 Release 签名／Profile，核对 Profile 绑定的包名与 AGC 应用相同；用 DevEco Studio 的签名配置生成正式 Release 产物并查看签名状态，不能把 `entry-default-unsigned.hap` 作为提审包。密钥库、密码、证书私钥和 Profile 原件由你安全保存，**不要提交到仓库或聊天**。可按[华为签名与发布流程](https://developer.huawei.com/consumer/cn/blog/topic/03186790383988145)在 DevEco Studio/AGC 操作；若你启用了 AGC App Signing，先确认控制台选择的密钥管理方式，再配置上传证书。
4. 完成应用图标、介绍、分类、截图、权限用途和隐私材料。截图最好等本轮视觉设备复验完成后再拍，避免展示旧色档。最后用一台真实 API 26 手机完成发布前走查；模拟器通过不代替真机结论。
