# 云同步故障手动重试：设备验收

状态：代码/离线/构建证据与设备证据分开记录；本文件不以出包成功替代设备实测。请在两台可丢弃且已配对的 API 26 设备上执行，不卸载、不清数据、不解除配对。

1. A 保持已配对，暂时关闭网络；在 A 改一处容易辨认的班表并保存，等待至少 6 秒。预期本机保存成功；「我的 → 伴侣与同步」出现「云同步暂时没成功」和「手动重试」；「同休」「共同时间」不出现云同步失败条。它们其他本机过期/计算提示不在本条范围。
2. A 恢复网络，但先**不要**按手动重试；再改一次班表并等待至少 6 秒，退出/重进三个 Tab。预期「我的」仍显示失败状态，B 下拉刷新后仍看不到 A 的这两次新改动。这一步验证跨页面与保存动作不会暗中重试；跨日不必人为改系统时间，离线纯函数测试覆盖该判据。
3. A 在「我的 → 伴侣与同步」点一次「手动重试」。预期按钮显示「同步中…」，结束后失败条消失，并提示「已同步最新班表」。B 下拉刷新后能看到 A 的最新班表对共同时间的影响。若仍失败，记录 A 卡片的完整标题与正文，不要反复连点。
4. 若要复验失败分支：A 再次断网、改班表、等失败条出现后点手动重试。预期失败条仍在，本机改动仍在；恢复网络后再次手动重试才恢复。请勿为了构造配额/鉴权失败而改线上 AGC 设置或删除配对。

设备记录：设备系统版本、两台包版本、四步逐项结果、失败时的完整文案、恢复后 B 的可见变化。`QUOTA_EXHAUSTED` 是预防性错误映射，未经服务端真回包不判它曾发生。
