# 作息面板与系统调色直达交接

日期：2026-10-03。结论：本机门禁全部通过，视觉和系统弹窗交互待用户实测。本轮没有操作模拟器。

更新：已依据用户截图完成第二轮间距与对齐调整。当前作息高度为 **46%**、顶部留白 **20vp**，数字放在行末，自定义调色入口使用居中布局。下方第一轮的 40% 与单位位置为历史记录；本轮证据和检查项见末节。

## 已落地

### 作息设置

作息面板为约 40% 屏高的独立贴底布局。标题加粗，取消/保存固定在底部，底部保留 24vp 内边距，正文有自己的滚动区域。

起床、就寝改为并排时间按钮，小标签在上、较大时间在下；点击直接打开系统的 24 小时制时间选择器。只在系统“确定”回调更新草稿；关闭作息、保存中、重新打开作息或发起更新一次选择后，迟到回调不再覆盖当前草稿。时间按钮直接观察页面状态，不把动态读数按值传入 Builder。

睡前准备和往后计算合为两行设置，标签在左、数值及单位在右。原服务校验、保存和重算没有替换。最短共同时段默认显示“1小时 / 2小时 / 4小时”，位于标签右侧；选中项浅粉底、深色字。历史非标准值仍保留，选项区在小屏或大字体下可以换行，正文可以滚动，不扩大为全屏页面。

### 自定义颜色

班次编辑器的颜色预设末尾直接使用系统 `HdsColorPicker` 按钮，不再跳转应用内第二层“自定义颜色”面板。“返回 / 使用此颜色”及对应第二份草稿状态已经删除。

选色回调更新班次编辑草稿和颜色预览，只有“保存班次”会持久化。关闭班次编辑器后或保存中，不接受选色回调。每次编辑班次时初始化为该班次的颜色，点击预设色后也同步系统入口的初始颜色。

组件布局盒为 44×44vp、彩色圆半径为 13vp，没有另加点击层截获系统入口。实际原生触摸范围、回调时机和系统窗口关闭行为仍待实测；API 26 声明没有提供应用可接的选色取消回调，不能把“退出系统调色窗”直接等同于“撤销当前草稿颜色”。**可以确定的是：取消班次编辑不写库。**

## 请用户操作

无需卸载或清空数据。在 DevEco 对当前项目重新 Run，覆盖安装后检查：

1. **我的 → 作息**：约四成屏高；时间并排，数字参数两行，最短时段默认三个选项在标签右边，底部操作不贴手势条。请提供完整截图，便于确认实际屏高与剩余留白。
2. 点击起床：选择一个不同时间，先在系统弹窗取消，时间应不变；再选择并确定，面板读数应立即更新。就寝重复一次，包括凌晨时间。
3. 改两项数字和最短时段后取消作息，再打开应为原保存值；重新修改并保存，再打开应为新值。往后计算仍只能保存原服务允许的范围。
4. **班表与班次 → 班次类型 → 点一个班次 → 自定义颜色**：一次点击进入系统调色窗口，不应出现截图中的大面积空白中间面板。
5. 在色谱、网格或滑块中选色后退出系统窗口，检查班次表单预览；再取消班次编辑，列表色块应未改变。重新选色并保存班次，列表色块应更新；再次编辑该班次时应以新颜色起步。
6. 点击一个预设色，再打开自定义颜色，核对起始色与预设一致。连续两次打开系统调色窗，核对后一次的起始色与当前预览一致；若拖动时被跳回旧颜色，请记录所用页签和屏幕录像。
7. 如方便，在深色模式及大系统字体下打开作息，检查文字不被剪掉、数字键盘出现后正文能滚动到输入项、取消/保存仍可操作。检查后恢复原设置即可，不必卸载。

## 第二轮：用户截图反馈后的微调

- 作息高度由 40% 调为 46%；标题顶部留白由 8vp 改为 20vp，标题/正文/操作区间隔由 6vp 调为 10vp。仍是贴底弹窗，不变全屏。
- 睡前准备与往后计算的单位移入左侧标签：“睡前准备（分钟）”“往后计算（天）”。两项数字输入框都为 80vp，水平内边距为 0、文字右对齐，数字后不再有单位列，右边缘一致。数字使用应用正文墨色，深浅色资源照常跟随。
- 截图显示系统调色圆偏左上；原先把系统组件外框设成了 44vp，但内部圆没有跟着居中。现在使用 44×44vp 的 `Stack({ alignContent: Alignment.Center })` 布局格，内部系统按钮为 26×26vp，保持原生打开方式、初始颜色与草稿回调不变，不新增点击层或中间面板。
