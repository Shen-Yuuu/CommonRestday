# 周班表与「＋日程」验收

> 后续规则更新：2026-10-10 用户选择「未安排不占用时间」，本文件的未知日期保守占用描述已被 [最新验收](2026-10-10-roster-page-consistency.md) 替代。常用班次现位于周班表标题栏右侧。

## 已完成

- 周班表改为真实日期的周一至周日；支持同日多班、单班多个时段，以及休息／未安排。
- 常用班次是时间组合。放入某日后存为独立快照，之后修改常用班次不会追改已保存的新班表。
- 保存本周仅保存这一周；复制和按周重复都需要选择目标范围及保留／替换／合并策略。
- 实际工作重叠，包括跨午夜、跨周，阻止保存；与课程、个人安排、共同计划、通勤或恢复的重叠需要明确确认，原有安排不会被静默删除。
- 首页「今天 → ＋日程」提供个人安排和工作排班；个人安排无需双方确认，工作排班可选任意日期。
- 「日程管理」不再显示临时调整入口。周历点日期后的「改这天」仍保留，与「＋日程」复用同一个新编辑组件。
- 旧循环和旧单日覆盖保留读取；新日期记录优先，未改日期继续按旧规则计算。没有清空或自动改写用户数据。

## 你的设备测试步骤

### 1. 保留数据覆盖运行

使用 DevEco 运行更新后的主项目，保持相同应用标识及签名，覆盖安装，不卸载、不清数据。先确认原来的班表、课程、计划和配对仍在。此次无需重新部署云函数。

### 2. 常用班次与周班表

1. 打开「我的 → 班表与课程」，默认显示周班表；管理页只有常用班次、周班表、课程表，不再有临时调整。
2. 从周班表右上角进入「常用班次」，新建「分段班」，添加 09:00–12:00、14:00–18:00 两个时段；先把通勤和恢复设为 0，便于检查空档。
3. 回到周班表，点选一个日期加入分段班，再点「完成本日安排」。此时只形成周草稿；点「保存本周」才落库。重新进入或重启后应仍在。
4. 同一日期还可添加其他不重叠班次。尝试再加 11:00–15:00，应该提示工作重叠，不能保存；12:00–14:00 与前后端点接续允许保存。
5. 修改常用分段班的名称或时间，再回看已保存日期：原日期不应变化。点该日已安排班次可以仅修改它的时间快照。

### 3. 跨夜、休息与未安排

1. 选择周日，安排 22:00–次日06:00；再在下周一安排 05:00–09:00，应阻止重叠保存；改为 06:00 之后才可保存。通勤／恢复造成的重叠会另行要求确认。
2. 将一个日期标记为「休息」，另一个保留「未安排」，保存后检查共同周历及首页。
3. 已启用工作排班时，未填写日期暂不用于确认空闲，周历显示浅灰说明；休息日仍按作息、课程、个人安排及计划计算。不要把未安排当作休息。
4. 未使用工作排班、仅录课程或个人日程的用户，不会因为没填周班表而被全部屏蔽。

### 4. 复制、重复与草稿

1. 保存本周后点「复制 / 重复」，选下周或其他目标周。
2. 「保留」保留目标已有工作和明确休息；「替换」替换源周中已填写的日期；「合并」追加工作且重新检查冲突。源周未安排日期不清空目标。
3. 选择开始周、结束周进行有限重复，确认只写入所选范围，不自动延长到未来所有日期。一次目标跨度不超过一年。
4. 修改当前周但不保存，切换周、切换代录对象或返回时应提醒；切到日程管理再切回来，周草稿应保留。单日编辑器改日期前也会提醒未保存修改。

### 5. 「＋日程」与个人安排

1. 首页「今天 → ＋日程 → 工作排班」选择另一天，修改班次并保存，核对周班表对应日期；不应改变其他日期。
2. 选择「个人安排」，创建今天的运动或办事安排；检查「今天」时间轴和忙闲计算，计划 Tab 不应出现待双方确认的邀请。
3. 再进入个人安排，从下方已存列表点选修改；仅与自己原时段相交时，不应误报重复冲突。与其他安排重叠时要求确认。
4. 删除个人安排，确认当天工作班次及其他个人日程保留；标记工作休息也不应删除个人安排。

### 6. 已配对两台设备

1. 两端均覆盖运行新版本，保持原配对。
2. A 保存工作班次或个人安排，等现有合并同步完成后，在 B 下拉刷新；检查共同空闲是否避开 A 新增的忙碌时间。
3. 按共享等级确认 B 只看到允许分享的信息，不应得到 A 个人安排的私密标题。
4. 尝试发起与 A 新班次或个人安排重叠的共同计划，应走现有冲突检查；不重叠的空档仍可安排。未填写的工作日期按保守规则处理。
5. 最后重启双方，确认新班表、个人安排及原共同计划仍然存在。

布局重点观察：七个日期按钮是否一行完整、票签行的分段文字是否换行正常、编辑器长内容是否可滚动、底部弹窗是否遮挡保存按钮、日程管理与周班表切换是否有闪烁。实际效果不合适的位置可截图继续调整。
